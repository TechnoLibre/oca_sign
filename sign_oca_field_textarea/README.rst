This module adds the *Multi-line Text* type to the fields of sign_oca
documents.

On the signing page, such a field is a text area that fills its box:
Enter starts a new line, the box scrolls when the text is taller than
it, and Tab moves to the next field. When the document is signed, the
text is drawn in the PDF from the top of its box, with its line breaks;
lines wrap to the width of the box, and what passes its bottom is cut.

   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Usage
=====

Add a multi-line field
----------------------

- Go to Sign / Settings / Fields and create a field, for instance
  *Remarks*, with the type *Multi-line Text*.
- In the editor of a template or of a draft request, right-click the
  page and choose that field. Its box shows a paragraph icon; give it
  the height of the lines it must hold.
- The signer types the text in the box on the signing page; it is
  printed in the document when it is signed. A box smaller than about
  six lines, as on a phone where the page is scaled down, grows over the
  page while it is being typed in, with a larger font, and goes back to
  its size afterwards.

For developers
--------------

- ``sign.oca.request.signer._get_pdf_page_textarea(item, box)`` draws
  the item; it reuses sign_oca's ``_get_pdf_text_markup``, so the value
  is escaped and keeps its line breaks.
- ``sign.oca.request.signer._get_pdf_textarea_style()`` returns the
  reportlab paragraph style of the text; by default the one of
  sign_oca's text fields (``_getParagraphStyle``).
- The item boxes of the document frame carry a ``data-field-type``
  attribute, for stylesheets that target one field type.
- Uninstalling the module turns the multi-line fields into one-line text
  fields.
