This module lets a sign request require its signers to log in.

A template, and each request, gets a *Require login* option. A request
created from a template takes the template's value; the value can change
on the request while it is a draft, and is read-only once the request is
sent.

When the option is set, every ``/sign_oca/*`` page of a signer requires,
on top of the signer's access token, a session whose user is linked to
the signer's contact (the contact itself or one of its parents, as in
the portal list of sign requests). An anonymous visitor goes to the
login page and comes back to the document afterwards; another user is
sent to their portal home. The same check applies when signing from
code: ``action_sign`` refuses any user who is not the signer.

Without the option, a request keeps the token-only access of
``sign_oca``.

Usage
=====

- Go to Sign / Templates, open a template and tick *Require login*.
- Send a request from that template: the request has *Require login*
  set.
- For a request created without a template, tick *Require login* on the
  request before sending it.
- Each signer needs a user (portal or internal) whose contact is the
  signer's contact or one of its parent contacts; a signer without such
  a user cannot sign the request.
- The signer opens the link of the invitation e-mail, logs in, and is
  brought back to the document to sign it.
