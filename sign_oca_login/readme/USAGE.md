- Go to Sign / Templates, open a template and tick _Require login_.
- Send a request from that template: the request has _Require login_ set.
- For a request created without a template, tick _Require login_ on the request before
  sending it.
- Each signer needs a user (portal or internal) whose contact is the signer's contact or
  one of its parent contacts; a signer without such a user cannot sign the request.
- The signer opens the link of the invitation e-mail, logs in, and is brought back to
  the document to sign it.
